# Planejamento de Testes - AnotAI

Atividade de planejamento de testes da disciplina de Novas Aplicações em Engenharia de Software (NAES), elaborada com base no projeto [rafaelzottesso/naes2026](https://github.com/rafaelzottesso/naes2026).

## Artefatos criados no Testiny

- Projeto: `AnotAI - Gestão Financeira`
- Chave: `ANOT`
- Pasta de casos: `Funcional - AnotAI`
- Plano: `Plano de Testes - AnotAI Gestão Financeira`
- Casos de teste: 10 casos funcionais
- Execução: não iniciada, pois será registrada em uma atividade posterior

O documento completo está em [plano-de-testes-anotai.md](plano-de-testes-anotai.md).

## Rastreabilidade

O planejamento foi derivado das regras do módulo financeiro do projeto-base: cadastro de pessoas, validação de documentos, lançamentos à vista e parcelados, pagamentos, situação das parcelas e isolamento dos registros por usuário.
